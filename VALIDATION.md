Разность числа принятых и выданных элементов ожидаема: тест намеренно сбрасывает
непустой FIFO, удаляя старые транзакции согласно контракту. В конце оставшаяся
очередь полностью опустошена. Начальное состояние PRNG фиксировано в тесте;
это направленный и псевдослучайный прогон, не исчерпывающее доказательство.

Локальный симулятор получен из
[пакета MSYS2 Icarus](https://packages.msys2.org/packages/mingw-w64-ucrt-x86_64-iverilog)
с проверкой SHA-256 пакетов; исполняемые файлы и библиотеки не включены в репозиторий.
Команда выполненного прогона:

```text
python tools/simulate.py --iverilog build/iverilog-local/ucrt64/bin/iverilog.exe --vvp build/iverilog-local/ucrt64/bin/vvp.exe
```

PDF собран ReportLab 5.0.1 и markdown-it-py 4.2.0 на Python 3.10 с Arial/Consolas.
Структура проверена pypdf 6.19.0; выбранные страницы отрисованы PyMuPDF 1.28.2
для визуального просмотра. PyMuPDF не требуется для обычной сборки.

Симуляция `core.sv`, `verification.sv`, `primitives.sv`, `sv2023.sv` не выполнялась:
для них подтверждена только компиляция. Отдельные runtime-возможности требуют
подходящего симулятора. GitHub Actions настроен, но удалённый CI в этой сессии
не запускался; локальные проверки не подменяются заявлением об успешном CI.

## Воспроизводимые команды

```text
python tools/book.py toc
python tools/map_plan.py
python tools/book.py check
python tools/check_sv.py
python -m unittest discover -s tools/tests -v
python tools/book.py build
python tools/check_pdf.py
python tools/simulate.py
```

`book.py check` проверяет манифест, полноту списка глав, оглавление README,
существование локальных целей и якорей. Сетевые ссылки не запрашиваются
при каждой сборке, чтобы сборка оставалась автономной.

`check_sv.py` компилирует пять независимых наборов через pyslang 11.0.0:
FIFO, типы/выражения, средства проверки, примитивы и дополнения 2023.
Для каждого используются соответствующие режимы 1800-2017/1800-2023.
Все пять наборов прошли без ошибок и предупреждений. Это семантическая
проверка и элаборация, не выполнение симуляции.

`check_pdf.py` проверяет заголовки всех глав, извлекаемую кириллицу,
внутренние/внешние ссылки и закладки. Визуальная проверка дополняет её:
автоматический поиск текста не доказывает отсутствие наложения строк.

Короткие листинги в тексте могут быть фрагментами, требующими пояснённого
контекста. Проверенные автономные единицы находятся в `examples`.
Коммерческий синтез, FPGA place-and-route, formal и CDC/RDC-анализ не выполнялись;
методичка не заявляет результаты этих этапов для учебного FIFO.
