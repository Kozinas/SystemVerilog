# 06. Операции, размер и знаковость

При чтении выражения нужно ответить на три вопроса: какой оператор выполняется,
сколько бит участвует в вычислении и как эти биты интерпретируются по знаку.
Математически верная формула может дать неправильную аппаратную арифметику
из-за усечения промежуточного результата.

## Семейства операций

| Семейство | Операторы | Смысл |
| --- | --- | --- |
| Арифметика | `+ - * / % **` | Числовые действия |
| Сравнение | `< <= > >=` | Однобитный результат |
| Равенство | `== != === !== ==? !=?` | Обычное, case и wildcard equality |
| Логика | `! && \|\|` | Проверка истинности операндов |
| Побитовые | `~ & \| ^ ^~ ~^` | Отдельная операция над каждой позицией |
| Редукции | `& ~& \| ~\| ^ ~^` | Один результат из всех битов вектора |
| Сдвиги | `<< >> <<< >>>` | Логический или арифметический сдвиг |
| Выбор | `cond ? a : b` | Условное выражение |
| Сборка | `{a,b}`, `{N{a}}` | Конкатенация и репликация |
| Множество | `inside` | Принадлежность списку значений/диапазонов |

`a & b` и `a && b` различаются даже для обычных двоичных векторов.
При `a=2'b10`, `b=2'b01` побитовое AND даёт `00`, а логическое AND — `1`.
Унарная редукция `&a` отвечает, все ли биты равны единице.

`==` может вернуть X. `===` всегда даёт 0 или 1, считая X/Z самостоятельными
значениями. В `==?` X/Z правого операнда служат маской; левый операнд не получает
такой симметричной роли. В RTL сравнение с X не означает детектор физической
неизвестности. В тестбенче `!==` полезно, чтобы X не превратился в молчаливый пропуск.

## Размер вычисления

Часть выражений имеет self-determined размер: например, элементы конкатенации
определяют свои размеры до сборки. Другие получают размер из контекста присваивания
и соседних операндов. Поэтому правило «плюс всегда имеет ширину только входов»
недостаточно, но и надежда на последующее расширение уже усечённой части опасна.

```systemverilog
// Фрагмент модуля, комбинаторная арифметика.
logic [7:0] a, b;
logic [8:0] sum;
assign sum = {1'b0, a} + {1'b0, b};
```

Явное расширение делает перенос видимым независимо от читательских догадок
о распространении контекста. Для произведения двух W-битных беззнаковых чисел
нужно до 2W бит результата. В конкатенации `{a + b}` сумма вычисляется
в собственном контексте; скобки `{}` не аналог обычных `()`.

`$bits(T)` и `$bits(expr)` позволяют проверить размер. Сначала расширяйте
операнды до требуемого типа, затем выполняйте действие. Приведение готового
усечённого результата не восстанавливает потерянные биты.

## Signed и unsigned

Для обычной бинарной интегральной арифметики смесь signed и unsigned часто
приводит к беззнаковой интерпретации. `logic signed [7:0] s` может хранить -1,
но сравнение с беззнаковым вектором требует особого внимания. Конкатенация,
bit-select и part-select дают unsigned-результаты; `$signed` меняет трактовку
битов, но не увеличивает их число.

```systemverilog
logic signed [7:0] value;
logic signed [8:0] extended;
assign extended = {value[7], value};
```

В этой записи расширение знака выполнено явно, а signed-объявление приёмника
задаёт дальнейшую интерпретацию. `>>>` заполняет старшие позиции знаком только
для signed левого операнда. `>>` вдвигает нули. `<<<` не создаёт особого
«знакового заполнения слева»; оба левых сдвига вдвигают нули справа.

## Условие, множества и потоки

При однобитном неизвестном условии тернарный оператор для интегральных ветвей
объединяет результаты побитно: одинаковые биты сохраняются, различающиеся
становятся X. Процедурный `if` при неопределённом условии идёт в `else`.
Это важный источник различия X-поведения двух внешне похожих записей.

`addr inside {[8'h20:8'h2f], 8'h80}` описывает набор. `case (...) inside`
использует подобные правила выбора. `{>>{data}}` и `{<<8{data}}` — потоковые
операции: они укладывают/переставляют группы битов. Вторая форма обращает порядок
8-битных групп, а не обязательно порядок битов внутри байта. Всегда фиксируйте
размер группы и ожидаемый порядок на маленьком примере.

`let` объявляет параметризованное выражение в своей области видимости:

```systemverilog
// Фрагмент внутри модуля.
let accepted(v, r) = v && r;
```

Это не хранилище и не процесс. Константное выражение вычисляется при элаборации;
оно может вызывать допустимые константные функции, но не зависеть от текущего входа.

## Приоритет и побочные эффекты

Практический порядок: унарные операции, степень, умножение/деление, сложение,
сдвиги, отношения, равенство, побитовые, логические, условный выбор. Внутри
семейств есть дополнительные уровни. Смешанные выражения лучше явно группировать:
`(a == b) && enable`, `(mask & value) != '0`. Полная таблица — в LRM.
`++`, `--`, `+=` и присваивания в выражениях имеют побочные эффекты; в RTL их
удобнее оставлять в отдельных операторах, не полагаясь на порядок вычисления
разных аргументов вызова.

## Упражнение 06

Почему `8'sh80 >>> 1` и `8'h80 >>> 1` дают разные биты? Спроектируйте сумму
трёх 8-битных беззнаковых чисел без потери переноса и назовите нужную ширину.
