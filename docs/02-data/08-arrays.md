# 08. Массивы, очереди и методы

Packed-размерности записываются **до имени**, unpacked — после. Это не просто
разный стиль индексации: packed-массив является единым интегральным значением,
а unpacked-массив — набором самостоятельных элементов.

## Фиксированные массивы

```systemverilog
logic [3:0][7:0] packed_word; // Один 32-битный объект.
logic [7:0] memory [0:255];   // 256 отдельных восьмибитных элементов.
logic [7:0] image [0:15][0:31];
```

`packed_word[3]` выбирает старший байт, `memory[3]` — четвёртый элемент памяти.
Полный packed-вектор участвует в арифметике. Над всей unpacked-памятью оператор
`+` не превращается в поэлементное сложение. Для этого нужен цикл.

Фрагмент процедурного кода:

```systemverilog
foreach (image[row, col])
  image[row][col] = '0;
```

В RTL такой цикл описывает требуемую логику; он не растягивает очистку на
512 тактов. Полный сброс большой памяти может помешать выводу RAM-блока.
Границы в фиксированном объявлении постоянны при элаборации; индекс чтения
или записи может быть вычисляемым сигналом.

Assignment pattern `'{default: '0}` инициализирует совместимый массив.
Присваивание целого массива копирует элементы согласно правилам совместимости
типов, формы и размеров. Срез unpacked-массива сохраняет массивную природу;
он отличается от битового part-select packed-вектора. Конкатенация unpacked
массивов может соединять элементы и массивы подходящего типа.

## Динамический массив

```systemverilog
// Фрагмент тестбенча внутри initial.
int samples[];
samples = new[4];
samples[0] = 12;
samples = new[8](samples);
samples.delete();
```

`new[8](samples)` создаёт новое хранилище и копирует помещающуюся часть прежнего.
Без аргумента копирования старые данные не сохраняются таким способом.
`size()` сообщает текущую длину, `delete()` освобождает элементы.
Это программная модель памяти тестбенча, не переносимый RTL.

## Очередь и ассоциативный массив

```systemverilog
// Объявления и операции в тестбенче.
int pending[$];
int counters[string];
// pending.push_back(17);
// value = pending.pop_front();
// counters["read"]++;
```

Очередь имеет последовательные индексы, изменяет длину, поддерживает
`push_front`, `push_back`, `pop_front`, `pop_back`, `insert`, `delete`, `size`.
`[$:N]` ограничивает верхний индекс, то есть вместимость равна N+1. До удаления
элемента проверяйте непустоту: диагностическое поведение пустого pop не является
полезным протоколом. Присваивание очереди копирует элементы, но handles внутри
остаются ссылками на прежние объекты.

Ассоциативный массив выделяет только использованные ключи. Тип индекса задаётся
в скобках, например `[string]`. Методы `exists`, `num`, `first`, `last`, `next`,
`prev`, `delete` поддерживают поиск и обход. Отсутствующий ключ и значение,
равное нулю, — разные состояния; используйте `exists`, если это существенно.

## Методы и запросы размеров

| Группа | Средства | Что учитывать |
| --- | --- | --- |
| Геометрия | `$size`, `$left`, `$right`, `$low`, `$high`, `$increment` | Номер размерности существенен |
| Размерности | `$dimensions`, `$unpacked_dimensions` | Packed и unpacked считаются по правилам запроса |
| Биты | `$bits` | Размер представления, а не число элементов вообще |
| Поиск | `find`, `find_index`, `find_first`, `find_last` и варианты `_index` | Результат обычно очередь |
| Экстремумы | `min`, `max`, `unique`, `unique_index` | Это методы массива, не SVA/RTL-квалификаторы |
| Порядок | `sort`, `rsort`, `reverse`, `shuffle` | Меняют коллекцию |
| Свёртки | `sum`, `product`, `and`, `or`, `xor` | Следить за размером промежуточного значения |

Выражение `values.sum() with (int'(item))` расширяет каждый элемент до `int`
до суммирования. Без этого сумма узких элементов может иметь неожиданно узкий тип.
`find() with (item > 10)` выбирает элементы по условию. `item` — имя итератора;
в синтаксисе методов можно задавать собственное имя. В 2023 добавлен `map`
для преобразования элементов; поддержку режима языка проверяют отдельно.

Массивы передают подпрограммам по значению или по ссылке. Open array argument
с `[]` позволяет принять различные размеры unpacked-массива при совместимом
типе элементов. Для `ref` требования строже; правила — в
[главе 12](../03-language/12-subroutines.md).
